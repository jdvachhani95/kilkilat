# Watercolor memories

Three illustrated portraits were created from the hosts’ supplied photographs with the **built-in image generation tool**. The supplied pastel invitation screenshot was a style reference. After a first pass, the hosts requested a more illustrated treatment; the selected revisions simplify faces, clothing and foliage into softer painted shapes while retaining the original poses.

IMG_6929 leads the invitation. Aruni’s heart-hands portrait accompanies the February reveal; the Dad / Mom newspaper portrait accompanies the shower details. The original photos and reference screenshot are not published. Selected generated PNGs are retained as artwork sources, with lossless WebP copies preserving transparency used in the public build.
